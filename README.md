# Rachel's Path to Restoration

A deeply personal theological forecasting model exploring Rachel's journey toward considering the LDS faith.

## 🎯 About This Project

This is a nerdy, affectionate gift between close friends - a sophisticated probability model that tracks the likelihood of LDS conversion through theological barriers, life factors, lived witness, and yes... herbal tea sessions. It's built with love, humor, and genuine respect for the complexity of faith journeys.

## ✨ Features

### Core Dashboard
- **Real-time Probability Calculator**: Dynamic model incorporating 20+ variables across theological, life, witness, and playful metrics
- **Live Countdown Timer**: Tracks time remaining to projected conversion date (baseline: September 27, 2026)
- **Interactive Sliders**: Fine-tuned to 0.5 precision for nuanced adjustments
- **Probability Trajectory Graph**: Visual representation of faith journey progression from 68.2% to current 83.9%

### Theological Variables
- Coffee Dependency Index (negative factor)
- Grace vs. Works Gap (negative factor)
- Acceptance of Joseph Smith as Prophet
- BOM/D&C Divine Revelation Acceptance
- Ordinance-Based Salvation Acceptance

### Life Factors
- Family Reaction Concerns
- Life Stability & Rootedness
- Christ's Anchoring Need
- Community Integration
- Journey Timing Readiness

### Witness & Engagement Metrics
- Lived Faith Witness Exposure Hours
- Theological Conversation Frequency
- Scripture Reading Progress
- Hours Spent Mulling

### Key Spiritual Events
- Core Identity Alignment
- Celestial Considerations (eternal family bonds)
- Church Attendance
- Holy Spirit Prompted Revelation

### Playful Metrics
- Herbal Tea Sessions per Month
- Spiritual Meme Exchange Rate
- Late-Night Scripture Reading

### Scenario Modeling
- **Coffee Factor**: What if coffee wasn't a barrier?
- **Family Support**: What if family was fully supportive?
- **Grace/Works**: Internal resolution of theological questions
- **Snow Storm Toggle**: Life disruption modifier (reduces probability 25%, extends timeline 25%)

### Interactive Elements (ADHD-Friendly)
- **Clickable Snowflakes**: Satisfying pop animation with synthetic bubble-wrap sound
  - Slower fall speed (12-20 seconds) for easier targeting
  - 2.5x scale burst animation
  - Web Audio API pop sound on click
  - Automatic replacement after popping
- **Pulsing Snow Toggle**: Gentle breathing animation on floating button
- **Hover Effects**: Enhanced slider interactions with glowing drop-shadows
- **Confetti Burst**: Celebration animation triggers at 100% probability (150 pieces, physics-based fall)

### Context Pages
Two dedicated educational pages accessible via clickable superscripts:

1. **Joseph Smith Context** (superscript ²)
   - Historical revivalism map showing Burned-Over District
   - Museum-style explanation of Second Great Awakening
   - Zoomable full-screen image display
   
2. **Ancient Colophons Context** (superscript ¹)
   - Comparison of Genesis toledot formulas with Jacob 3:14
   - Hebrew text with KJV translations
   - Explanation of ancient Near Eastern documentary practices
   - Visual tablet comparison (Genesis examples vs. Book of Mormon parallel)

## 🎨 Design Philosophy

- **Aesthetic**: Warm beige/brown gradient backgrounds with gold accents
- **Typography**: Crimson Pro serif font for scholarly elegance
- **Responsiveness**: Fully responsive design with clamp() functions
- **Accessibility**: High contrast, readable fonts, smooth scrolling
- **Playfulness**: Balance between serious theological discussion and lighthearted metrics

## 🛠️ Technical Stack

- **Frontend**: React 18 with Babel standalone
- **Styling**: Inline styles with CSS animations
- **Analytics**: Google Analytics (G-7C0JK4S0T9)
- **Audio**: Web Audio API for synthetic sound effects
- **Deployment**: GitHub Pages
